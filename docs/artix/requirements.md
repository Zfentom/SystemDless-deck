# Requirements

Before starting, make sure you have:

- A Steam Deck
- A USB-C hub, dock, or USB-C adapter
- A USB flash drive or other storage device for flashing the installation image
- A keyboard (recommended)
- A stable internet connection
- A backup of any important data

## Optional

These are not required, but may make the installation process easier:

- An external mouse
- An external monitor
- A second device for reading the documentation while installing
